# Мал хариулах

49.12215° N, 104.6872° E өвөлжөөний бодит газар дээр морь, мотоцикл унаж мал хариулах 3D тоглоом (Three.js).

🌐 **Онлайн:** https://mal-hariulah.vercel.app

## Компьютер дээр ажиллуулах
```
cd C:\Users\User\projects\mal-hariulah
npm start
```
- Компьютерээс: http://localhost:5190
- Утаснаас (нэг Wi-Fi-д холбогдсон үед): терминалд гарах `http://10.x.x.x:5190` хаягаар

## Vercel руу шинэчлэх
```
npm run deploy
```
(`public/index.html`-г дахин үүсгээд production руу байршуулна. Бүртгэл: turuu1201)

## Бүтэц
| Файл | Үүрэг |
|---|---|
| `src/page.html` | Тоглоомын эх (өгөгдөл, код бүгд нэг файлд) |
| `build.mjs` | `src/page.html` → `public/index.html` (бүтэн HTML, PWA холбоос) |
| `public/` | Байршуулах файлууд: index.html, manifest, sw.js, тэмдгүүд |
| `server.mjs` | Хамааралгүй энгийн дотоод сервер |
| `data/` | Газрын өндөр (SRTM), хиймэл дагуулаас зурсан объектууд |

## Утсаар тоглох
- Зүүн доод буланд жолоо, баруун талд товчнууд гарна.
- Нэг хуруугаар чирж камер эргүүлнэ, хоёр хуруугаар чимхэж ойртуулна.
- ⛶ товч — бүтэн дэлгэц (Android). Утсаа хэвтээ барина.
- Хөтчийн цэснээс **“Нүүр дэлгэцэнд нэмэх”** дарвал апп шиг суулгана; нэг нээсний дараа интернэтгүй ч ажиллана.
